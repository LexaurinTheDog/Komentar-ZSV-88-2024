# Komentář k zákonu č. 88/2024 Sb., o správě voleb

Otevřený komentář k zákonu o správě voleb — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; volební orgány a registrační úřad, informační systém správy voleb, registrační řízení, okrskové volební komise, organizace hlasování, hlasování v jiném okrsku, podpora osob se znevýhodněním, zjišťování výsledků, financování a soudní přezkum.

Konsolidované znění: dokument e-Sbírky `SB-2024-00088_2026-01-01`.
